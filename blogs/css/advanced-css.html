Advanced Styling

Text & Image Shadow Effects

There are two ways where you can add shadow effects to your elements:

  • text-shadow: - adds a shadow effect to the selected text.
  • filter: drop-shadow() - adds a shadow effect to an image.

This can be done as easy as 1, 2, 3! Just specify the horizonal and vertical shadow, and its color.

Gradients

The CSS gradient functions lets you display a smooth transition between two or more colors in an element. These functions are used within the background-image property.

There are three types of gradients in CSS:

  • linear-gradient: - color transition goes down, up, left, right, or diagonally.
  • radial-gradient: - color transition goes out from the center point like a circle halo.
  • conic-gradient - color transition rotates around the center point.

When mentioning the syntax, it looks like this:

background-image: linear-gradient(direction, color-1, color-2);

You can specify the direction by telling it like this: to bottom, to top, to right, to left, to bottom right, etc.

CSS also supports repeating linear gradients and is used like this:

#grad {
  background-image: repeating-linear-gradient(red, yellow 10%, green 20%);
}
