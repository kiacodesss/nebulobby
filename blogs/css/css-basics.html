Intro to CSS

Now that we've already gone over the basics of HTML, let's bring life to your profile with CSS! Just a heads up, I will be separating this lesson into two blogs: CSS Basics and Advanced CSS. In CSS Basics, I will be explaining the properties and selectors used to add styling to your HTML elements. While, in Advanced CSS, we will go further deeper into CSS by learning about cool animations, keyframes, and effects!

In this lesson, expect that we're going to use both HTML and CSS now so that you'll get a gist on how they work together. This also means that we'll still be using an online compiler to test out the codes so be sure to ready it on the side!

CSS 101

What is CSS? CSS stands for Cascading Style Sheets, they are solely responsible for making your webpage look pretty by adding colors, animations, a cool layout, and more, to your liking! In CSS, we use properties and selectors to assign styling rules to your HTML elements.

But hold on! How do you comment in CSS? Well, we can do it this way:

  • /* Text */ - for commenting a single-line text or a block of text with multiple lines, and should be closed at the end.

One more thing that you should always keep in mind, when it comes to assigning properties to an HTML element, you have to first specify what HTML element you want to assign and then use curly brackets { }, inside those brackets are the properties.

CSS Properties

In CSS, we have many properties that are used for different purposes. Don't worry if you don't memorize all of them at once, what matters is that you understand how they work. I'll be separating them into four subsections: texts, colors, images, and positioning.

Text Properties

  • font-family: - specifies the font you want for your text (eg., "Times", "Courier", "Arial", etc).
  • font-size: - specifies the font size using a number value in pixels or px for short (e.g., "200px").
  • font-weight: - controls the thickness of the text, it accepts either a word value or number value (e.g., "normal", "bold", "bolder" or "800", which is equivalent to bold).
  • text-align: - aligns text horizontally (e.g., "left", "center", "right", "justify").
  • text-transform: - controls the capitalization of text (e.g., "uppercase", "lowercase", "capitalize").
  • text-decoration: - adds decoration to a text if you want to add an emphasis (e.g., "underline", "overline", "line-through").
  • line-height: - controls the spacing between lines of text and can be set using number values (e.g., "1.5").

Color Properties

  • color: - sets the text color.
  • background-color: - fills the background of an element with a color you want.
  • border-color: - sets the color of an element's border like adding a yellow border to an image.

Important: There are three ways you can specify a color in CSS: the color name (e.g., "red", "blue"), the HEX value (e.g., "#fff000"), or the RGB value (e.g., "rgb(0, 0, 255)"). You can choose either one of the three.

If you want a simple color, use the color name but if you want a really specific color, you can either use a HEX or RGB value.

Image Properties

  • width: and height: - controls the dimensions of an image which can be specified by a number value in px (pixels) or just "auto".
  • max-width: and max-height: - helps make sure that images stay responsive when viewed on smaller screens, often set using a number percentage (e.g., "10%").
  • object-fit: - determines how an image scales inside its container, very useful for cropping or filling spaces (e.g., "contain", "cover", "fill").
  • border-radius: - rounds the corners of an image using a number value.

Positioning & Layout Properties

  • display: - determines how an element behaves in the layout flow (e.g., "block", "inline", "flex", "grid").
  • position: - defines how an element is positioned on the page (e.g., "static", "relative", "absolute", or "fixed").
  • margin: - creates space outside of an element's border (e.g., "0 auto").
  • padding: - creates space inside an element, between the actual content and the element border (e.g., "20px").
  • gap: - controls the space between items inside a Flexbox or Grid container (e.g., "10px";).

CSS Layout

Since layout is a very important concept in both HTML and CSS, it's best that dive deeper into it so you can understand how to layout your profile. In the section above, I mentioned some positioning and layout properties, those are just some of them and here I'll be explaining them more in detail.

First things first, let's talk about the box model layout. Every element you see on a webpage such as texts, images, and icons, are all made of rectangles. Not convinced? Look at the image below where I applied a universal styling to all the elements on SpaceHey using Inspect, you'll see that each element are all inside rectangles!

The Box Model

The box model is a box that wraps around every HTML element. Every box consists of four parts: content, padding, borders and margins. The image below illustrates how a box model looks like.

I'll explain the different parts again from the innermost part to outermost part in more detail:

  • Content - the content of the box, where the text and images live.
  • padding: - an invisible area around the content.
  • border: - goes around the padding and content.
  • margin: - an invisible area outside the border.

Look at the box-model image again, you'll notice that there are "top", "bottom", "left", and "right" added. Those are added to the layout properties when you want a specific rule applied to a specific side of the content. padding:, border:, margin: are all shorthand properties so that means if you apply just one value to them, it applies to all the sides around the content. 

div {
    width: 300px; /* Sets the width of the content to 300px */
    border: 15px solid green; /* Adds a 5px green border around the content on all sides */
    padding: 20px; /* Adds a 50px padding around the content on all sides */
    margin: 25px; /* Adds a 25px margin around the border on all sides */
}

However, if you want to apply different rules to each side that's where specific properties becomes really helpful.

div {
    padding-left: 5px; /* Adds a 5px padding on the left side of the content */
    padding-right: 8px; /* Adds an 8px padding on the right side of the content */
    margin-top: 10px; /* Adds a 10px margin on top of the content */
    margin-bottom: 5px; /* Adds a 5px margin on the bottom of the content */
}

/* And if you want to apply the same rule to their corresponding sides, you can do it like this instead! */

img {
    padding: 3px 5px; /* Adds a 3px padding to the top and bottom, then adds 5px to the left and right sides */
    margin: 5px 3px; /* Adds a 5px padding to the top and bottom, then adds 3px to the left and right sides */
}

Width and Height of an Element

Understanding how the box model works helps you size the width and height of an element correctly! However, when you set a width: and height: rule, it only applies to the content area. To calculate the actual total width and height of an element, you have to add the padding and borders too. 

div {
    width: 400px;
    height: 250px;
    border: 5px solid pink; /* 5px border for each side */
    padding: 10px; /* 10px padding for each side */
    margin: 5px; /* 5px margin for each side */
}

This is how the total element width and height is computed:

  • Total element width = width + left padding + right padding + left border + right border
  • Total element height = height + top padding + bottom padding + top border + bottom border

From the code example above, the total element width is 430 and the total element height is 280! And that's pretty much it. Congrats! Now you know how the box-model works!

Important: The margin property also affects the total space that the box will take up on the page, but the margin is not included in the actual size of the box. The box's total width and height stops at the border.

CSS Selectors

Moving on to CSS selectors, these selectors are used to find or select the HTML elements you want to style in CSS. There are many types of selectors, but for now, we're going to focus on the very basic ones that you'll probably going to need in styling your profile.

Element Selectors

An element selector selects HTML elements based on the element name. This is especially helpful if you want to add a styling to a specific an element in your HTML. For instance, you want to make all your paragraphs color red and center aligned, you can do it like this: 

.p {
    color: red; 
    text-align: center;
}

Class Selectors

The class selector selects HTML elemenets with a specific class attribute. In order to do this with CSS, you have to first enter a period . followed by the class name and then add the styling rules inside the curly brackets { }.

HTML Code

<!-- Class can be reused across multiple elements -->
<div class="card">
    <p>This is the first card.</p>
</div>

<div class="card">
    <p>This is the second card sharing the same style.</p>
</div>

CSS Code

/* Target a Class using the dot (.) symbol first*/
.card {
    background-color: #f9f9f9;
    border: 1px solid #ddd;
    border-radius: 8px;
    padding: 15px;
    margin: 10px;
}

Important: You can't make up new class names in CSS, for it to work, you should always make sure that the class name you're referring to actually exists in your HTML and is identical.

ID Selectors

The id selector uses the id attribute of an HTML element to select a specific element where you want to apply a unique styling to. In class selectors, you first enter a period, however, with id selectors you use a hastag # instead, then followed by the id name of your element. 

/* Target the ID using the hash (#) symbol */
#unique-banner {
    background-color: #ffcc00;
    color: #333333;
    padding: 15px;
    border-radius: 6px;
    text-align: center;
}

Universal Selectors

The universal selector selects all HTML elements on the page, to do this you have to use an asterisk * and assign properties to it. So that means if you apply a style rule using a universal selector it will affect everything on your page, which is why its called universal.

For example, this code below makes all the text in your page color blue, center-aligned, and all in uppercase letters.

* {
  color: blue;
  text-align: center;
  text-transform: upppercase;
}

Grouping Selectrs

The grouping selector selects all the HTML elements with the same styling rules. There are times when you might want the same styling applied to different HTML elements, instead of repeatedly typing the rules again, you can group all the HTML elements together and assign the styling rule once.

Before

h1 {
  text-align: center;
  color: red;
  font-weight: 800px;
}

h2 {
  text-align: center;
  color: red;
  font-weight: 800px;
}

p {
  text-align: center;
  color: red;
  font-weight: 800px;
}

After

h1, h2, p {
  text-align: center;
  color: red;
  font-weight: 800px;
}

Important: When grouping different elements into one selector make sure to separate them using a comma , just like the example above.

And lastly, let's focus a bit more on these layout properties: padding:, border:, and margin:. This code sample creates a simple 'About Me'box, go ahead and play with it!

HTML Code

<div class="profile-box">
    <h2>About Me !</h2>

CSS Code

/* The main profile container utilizing the Box Model */
.profile-box {
    /* --- Content Area --- */
    background-color: #ffe0cf;
    width: 300px;
    height: 400px;

    /* --- Borders (Shorthand) --- */
    border: 3px solid brown; /* 3px solid brown border on all sides */

    /* --- Padding (Shorthand & Side-Specific) --- */
    padding: 15px; /* Applies 15px padding to all sides */
    padding-left: 25px; /* Overrides the left side specifically */

    margin: 10px; /* Applies 10px margin outside the border on all sides */
    margin-top: 20px; /* Overrides the top margin specifically */
}
