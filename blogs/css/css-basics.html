Intro to CSS

Now that we've gone over the basics of HTML, let's bring life to your code with CSS! In this lesson, I will be separating this lesson into two blogs: CSS Basics and Advanced CSS. In CSS Basics, I will be explaining the different properties and selectors used to add styling to the elements in your HTML. While in Advanced CSS, we will go further deeper into CSS by learning about animations, keyframes, and cool effects!

Since, you already learned HTML, let's practice more on using both HTML and CSS so that you'll know how to connect them. This also means that we'll still be using an online compiler to test out the codes so ready your online compiler on the side!

CSS 101

What is CSS? CSS stands for Cascading Style Sheets, they are solely responsible for making your webpage look pretty by adding different colors, fonts, and more, to your liking! CSS uses properties and selectors to assign styling rules to your HTML elements.

When commenting in CSS, we can do it in two ways.

  • // Text - used for a single-line comment and uses two forward slash then followed by your comment text.
  • /* Text */ - used for commenting a block of text with multiple lines. It also uses a combination of a forward slash ( / ) and an asterisk ( * ), and should be closed at the end.

One more thing that you should always keep in mind, when it comes to assigning properties to an HTML element, you have to first specify what HTML element you want to assign and then use curly brackets { }, inside those brackets are the properties.

CSS Properties

In CSS, we have many properties that are used for different purposes. Don't worry if you don't memorize all of them at once, what matters is that you understand how they work. I'll be separating them into four subsections: texts, colors, images, and positioning.

Text

  • font-family: - specifies the font you want for your text.
  • font-size: - specifies the font size using a set number value in px (pixels).
  • font-weight: - controls the thickness of the text, you can either set it as a word like "regular", "bold", "bolder" or a number like "500" "800"
  • text-align: - aligns text horizontally, you can either set it as left, center, right, or justify.
  • text-transform: - controls the capitalization of text which can be set as uppercase, lowercase, or capitalize.
  • line-height: - controls the spacing between lines of text and can be set using number values.

Colors

  • color: - sets the text color
  • background-color: - fills the background of an element with a color you want
  • border-color: - sets the color of an element's border like adding a yellow border to an image.

Images

  • width: and height: - controls the dimensions of an image which can be specified by a number value and set in px (pixels) or just "auto"
  • max-width: and max-height: - helps make sure that images stay responsive when viewed on smaller screens, set using a number value as percentage.
  • object-fit: - determines how an image scales inside its container, useful for cropping or filling spaces
  • border-radius: - rounds the corners of an image, often used to make square photos circular

Positioning & Layout

  • display: - determines how an element behaves in the layout flow, such as block, inline, flex, or grid (e.g., display: flex;).
  • position: - defines how an element is positioned on the page (e.g., static, relative, absolute, or fixed).
  • margin: - creates space outside of an element's border (e.g., margin: 0 auto; to center a block).
  • padding: - creates space inside an element, between the content and the border (e.g., padding: 20px;).
  • gap: - controls the space between items inside a Flexbox or Grid container (e.g., gap: 10px;).

CSS Selectors

Moving on to CSS selectors, they are used to find or select the HTML elements you want to style. There are many types of selectors, but for now, we're going to focus on the very basic ones that you'll probably need in styling your profile.

Element Selectors

An element selector selects HTML elements based on the element name. This is especially helpful if you want to add a very specific styling to an element. For instance, you want to make all your paragraphs color red and center aligned. 

.p {
    color: red; 
    text-align: center;
}

Class Selectors

The class selector selects HTML elemenets with a specific class attribute. In order to do this with CSS, you have to first enter a period ( . ) followed by the class name then the { }.

HTML Code

<!-- Class can be reused across multiple elements -->
<div class="card">
    <p>This is the first card.</p>
</div>

<div class="card">
    <p>This is the second card sharing the same style.</p>
</div>

CSS Code

/* Target a Class using the dot (.) symbol */
.card {
    background-color: #f9f9f9;
    border: 1px solid #ddd;
    border-radius: 8px;
    padding: 15px;
    margin: 10px;
}

Important: You can't make up new class names when styling in CSS, for it to work, you should always make sure that the class you're referring to actually exists in your HTML and is identical.

ID Selectors

The id selector uses the id attribute of an HTML element to select a specific element where you want to apply a unique styling to. In class selectors, you first enter a period, however, with id selectors you use a hastag # instead, then followed by the id name. 

/* Target the ID using the hash (#) symbol */
#unique-banner {
    background-color: #ffcc00;
    color: #333333;
    padding: 15px;
    border-radius: 6px;
    text-align: center;
}

Universal Selectors

The universal selector selects all HTML elements on the page, to do this you have to use an asterisk * and assign properties to it. So that means if you apply a style rule using a universal selector it will affect everything on your page, which is why its called universal. 

* {
  text-align: center;
  color: blue;
}

Grouping Selectrs

The grouping selector selects all the HTML elements with the same styling rules. There are times when you might want the same styling applied to different HTML elements, for it to be less repetitive, you can group all the HTML elements together and assign the rule you want. Grouping selectors will help you save code lines!

Before

h1 {
  text-align: center;
  color: red;
  font-weight: 800px;
}

h2 {
  text-align: center;
  color: red;
  font-weight: 800px;
}

p {
  text-align: center;
  color: red;
  font-weight: 800px;
}

After

h1, h2, p {
  text-align: center;
  color: red;
  font-weight: 800px;
}

Code Examples

Blah blah

HTML Code

<div id="profile-banner">
    <h1>Jane Doe</h1>
    <h2>Web Developer</h2>
    <p>Welcome to my personal corner of the internet!</p>
    
    <div class="bio-box">
        <p class="highlight">I love coding and building simple websites.</p>
    </div>
</div>

CSS Code

/* 1. Universal Selector */
* {
    box-sizing: border-box;
    font-family: sans-serif;
}

/* 2. Grouping Selector */
h1, h2 {
    text-align: center;
    color: #2c3e50;
}

/* 3. Element Selector */
p {
    color: #555555;
    font-size: 15px;
}

/* 4. Class Selector */
.highlight {
    background-color: #ffeb3b;
    padding: 4px;
}

/* 5. ID Selector */
#profile-banner {
    background-color: #e0f7fa;
    padding: 20px;
    border-radius: 10px;
}

HTML Code

<div id="main-article">
    <h2>CSS Basics</h2>
    
    <div class="card">
        <h3>Selectors</h3>
        <p>Selectors help you target elements easily.</p>
    </div>
    
    <p>Thanks for reading!</p>
</div>

CSS Code

/* 1. Universal Selector */
* {
    margin: 0;
    padding: 0;
}

/* 2. Grouping Selector */
h2, h3 {
    color: #d63384;
}

/* 3. Element Selector */
p {
    color: #333333;
    line-height: 1.5;
}

/* 4. Class Selector */
.card {
    background-color: #ffffff;
    border: 1px solid #dddddd;
    padding: 15px;
    border-radius: 6px;
    margin: 10px 0;
}

/* 5. ID Selector */
#main-article {
    background-color: #f8f9fa;
    padding: 30px;
}
