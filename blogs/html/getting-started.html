Intro to HTML

When it comes to creating any website or page on the web, you need the holy trinity: HTML, CSS, and Javascript! They are the backbone of every webpage you see on the internet, without it, you'll probably only see a plain white screen in every site you visit. Luckily, in websites like Spacehey, you don't have to to do any Javascript at all! Hooray! Moreover, this blog will focus solely on the basics of HTML and how you can structure your profile the correct way! I'll try to explain it as simple as I can.

What is HTML actually? HTML is short for HyperText Markup Language, it structures your webpage so that it's clean and well-put together. Think of it as the builder like Felix from Wreck-it-Ralph!

Important: As we go over the lessons, I will be sharing some code samples. To test the codes, you can use an online compiler like CodeChef to help you run the code easily.

HTML 101

In HTML, we use tags, attributes, and classes to keep things in place. They are used to define every content inside your page whether its a simple text or an image, you absolutely still need them! I will go over each of them in the following sections and explain them in more detail.

Elements

HTML uses tags which we call "elements." An HTML element is everything from a start tag to the end tag. Tags in HTML are always enclosed by "< >" signs, and end tags always has a forward slash inside like:

<h2>This is an example.</h2>

In the example above, <h2> is the start tag, while </h2> is the end tag. Now that you know what are the kinds of tags, these are the actual tags that you'll probably need in coding your profile:

  • <h1> - this defines the most important heading! It ranges from h1 (being the largest) and h6 (the smallest).
  • <p> - defines a paragraph or simply a block of text.
  • <br> - inserts a single line break, insanely useful for making lists or if you want to add an extra line space between texts or images.
  • <img src> - embeds an image or gif anywhere on your page!
  • <center> - centers the contents inside the tag.
  • <span> - an inline element used to style a specific portion of text.

Important: Always make sure that you use these "< >" when mentioning HTML tags.

The Attributes

HTML attributes provide additional information about HTML elements. It's important to keep in mind that all HTML elements can have attributes and they are always specified in the start tag.

  • <src> - specifies the actual source path of a media like an image address, so that it knows what image are you referring to.
  • <width> <height> - you can absolutely use width and height attributes to specify an image's dimensions (in pixels). These attributes can be added inside th <img src=" "> tag, right after specifying the source path.
  • <alt> - this shows an alternate text that will show if an image is unable to load correctly or when a user uses a screen reader.
  • <style> - this attribute is used to add styles to an HTML element (e.g., color, font, size, and etc.)

Important: When it comes to specifying the source path of an image in an <img src=" "> tag, make sure that you put it inside the quotation marks! This is the same for every attribute you will be using.

Classes & Identifiers

Onto the more interesting part of HTML is the classes and identifiers. They are global attributes used to identify and target elements for styling. They are genuinely a game changer when used with CSS!

To explain it better, just think of classes and identifiers as containers. For example, you want to create a vinyl gallery of your favorite albums, in HTML you need a class to put all the code for the vinyl gallery in a container so that it doesn't affect the other elements outside of that container.

When making a class, we use the <div> tag, followed by either a <class> or an <id>, then assign its value inside quotation marks like this:

<div class="elijah-woods">
<div id="elijah-woods">

  • <class> - a class is used when you want to give multiple elements the same styling.
  • <id> - you use this when you want to apply a completely unique styling to a specific element.

The Art of Nesting

HTML elements can be nested all the time, which is why learning the art of nesting is incredibly helpful in the long run. Nested elements are elements that are placed entirely inside another element. This is where the parent-child tree comes into the picture.

When nesting elements, they must be closed in the exact opposite order that they were opened. A child element must always be closed using end tags before its parent elemet closes. Take this block of code below as an example. 

<div class="library">
    
    <div class="book-shelf">
        <p>This is an example :P</p>
    </div>
    
    <div class="book-title">
    Romeo and Juliet - Shakespeare
    </div>
    
</div>

In the code above, we used classes and also performed nesting! See how the book-shelf and book-title classes are inside the library class? We consider both book-shelf and book-title as the child elements, while the parent element is the library. Also, take a good look at how tags were opened and closed. The child elements were closed first just before the parent element was closed.

Important: You will encounter nesting A LOT when coding in HTML, especially when creating containers using classes or identifiers. So, it's very important that you understand this concept firsthand.
